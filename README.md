# Saintnuit — Portfolio

Premium editorial portfolio for Creative Director & AI Filmmaker.

## Live Site

**https://portfolio-site-beta-sand.vercel.app**

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Vercel

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build & Deploy

```bash
npm run build
vercel --prod
```
